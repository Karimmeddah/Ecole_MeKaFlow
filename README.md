# ELMAA — installateurs

Ce dépôt public contient seulement les installateurs d'ELMAA (logiciel de gestion d'école de musique), publiés
dans **Releases**. Le code est dans un dépôt privé.

ELMAA télécharge ses mises à jour d'ici. Chaque fichier est vérifié par son empreinte SHA-256, annoncée par le
service d'abonnement, avant d'être installé : un fichier modifié est refusé.

Pour installer ELMAA, utilisez le fichier remis par votre fournisseur, avec le fichier de licence de l'école.
